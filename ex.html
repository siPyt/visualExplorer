1. Path Quotes & Shortcuts
• Local module: '^/TARGET_WT.CV'
• External CM: 'CM_FEED_XV/DC1/PV_D' or '//LAB4/FC4-1/SP.CV'
• Always wrap paths with / in single quotes!
2. Read (=) vs. Stamp (:=)
• CND / Transition (Question): use =, != (or <>), <=, >=
• ACT / Step Action (Write): MUST use := (e.g. '^/OUT.CV' := 1.0)
3. Suffixes & Keywords
• .CV = Current Value • .ST = Health Status
• MODE.ACTUAL (check) vs MODE.TARGET (write)
• Unquoted keywords: CAS, MAN, AUTO, OOS, GOOD, BAD, True, False
