⚡ 10-Second DeltaV Expression Assistant Cheat Sheet (Tap to Expand — Verified CONFIG pp. 61–83)
1. Path Quotes & Prefixes
• External module: '//CM_FEED_XV/DC1/MODE.ACTUAL'
• Up 1 level: '^/TARGET_WT.CV' • Module-rel: '/PARAM'
• Named-set constant: 'vlvnc-sp:OPEN' (quoted Set:Value!)
2. Read (=) vs. Assignment (:=)
• CND / Transition: := is illegal! Use =, != (or <>), <=, >=
• ACT / SFC Action: MUST use := (retains value after step/ACT ends)
3. Modes & Status Constants
• Always test .ST >= GOOD (= GOOD misses GoodCascade!)
• Out of Service keyword is OS (not OOS!)
• DC blocks support only AUTO & CAS target modes (LO on interlock)
